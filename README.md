# Ruhig bleiben — Prototyp

Prototyp einer App für Polizeikontrollen in Baden-Württemberg: Situationen mit Sätzen zum Sagen, Frage per Sprache, Video ohne Ton, Aufnahme mit Einwilligung, Gedächtnisprotokoll, Fristen und Briefvorlagen.

Allgemeine Information, keine Rechtsberatung. Stand 25.09.2026, noch nicht anwaltlich geprüft. 15 Situationen, 32 Wissenskarten, alles auf Deutsch und Russisch (Umschalter DE/RU oben rechts); freiwilliges Profil nur auf dem Gerät für persönliche Hinweise; Suche getestet mit 275 Fragen auf Deutsch und Russisch, darunter 80 nie zum Einstellen benutzte.
